# Data Orbs

Two procedural glowing orbs, **Data Orb** and **Sphere Lines**, in one Blender scene. Built with Geometry Nodes, rendered in Cycles. No add-ons, no external files.

- **Requires** Blender 5.2 or newer.
- **Download** `data-orbs.blend` from the [latest release](../../releases/latest).
- **Try it in your browser:** download `web/index.html` and open it in Chrome. The camera features need an internet connection to load their models.
- **How to use it** and what every setting does: [MODIFIERS.md](MODIFIERS.md).
